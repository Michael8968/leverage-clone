# **App Name**: Leverage AI 电商平台

## Core Features:

- 角色模拟登录: 允许用户模拟不同角色（管理员、供应商、用户、创建者）登录，以便体验不同角色的功能和权限。
- AI 购物助手: 用户可以通过文字描述或上传图片，AI会分析用户需求，并给出个性化的商品推荐。The AI model acts as a tool that will sometimes ignore photo and prioritize description, sometimes the opposite, and sometimes using both.
- 需求池: 管理员可以发布、浏览和管理用户需求，并利用AI为需求匹配合适的商品或创意。
- 供应商中心: 供应商可以管理自己的产品/服务信息，包括产品信息的添加、更新和删除。
- 数据分析: 允许供应商上传CSV文件，AI会对上传的数据进行分析，并展示分析结果。
- 消息通知: 实现站内消息通知功能，例如：需求更新通知，创意推荐通知等。

## Style Guidelines:

- Primary color: A bright blue (#4EC6FF) to reflect technology and innovation.
- Background color: A light grayish blue (#F0F8FF) for a clean and modern feel.
- Accent color: A vibrant purple (#C183FF) to highlight AI-related features and interactive elements.
- Headline font: 'Space Grotesk' (sans-serif) for headings, providing a modern and tech-oriented look; body font: 'Inter' (sans-serif) for body text to maintain readability and consistency.
- Note: currently only Google Fonts are supported.
- Use clean, modern icons that align with the geometric shapes in the Leverage logo.
- Employ a clean, card-based layout with ample white space to improve readability and visual appeal. Keep consistent spacing and alignment throughout the interface.
